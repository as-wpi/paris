# PARIS fork — project instructions

Fork of `ekam-a3/paris` at `as-wpi/paris`; branch `features` carries everything since 0.6.0. Keep it mergeable upstream: pure numpy/pandas, each module depends only on `_core.py`, no new dependencies.

## Environment
- Library venv: `UV_PROJECT_ENVIRONMENT=~/.venvs/paris uv run ...` (never a `.venv` inside `~/Documents`: iCloud hides `.pth` files).
- Research scripts that import the rtl-screener / RTL-Kalman engines run in `~/.venvs/rtl-workspace/bin/python` (numba, pandas 3); they add `src/` to `sys.path`.
- Market data: FMP via keyring; cache in `research/data_cache/` (git-ignored; `research/fetch_fmp.py`). Use `/dividend-adjusted` — the `/full` endpoint has no adjusted close. Treasury endpoint returns ~60 rows per chunk.

## Library discipline
- Every public function has a golden case in `tests/cases.py`; regenerate with `uv run python -m tests.generate_expected <module>` and confirm zero pre-existing cases changed (compare parsed JSON, not diff lines — key reordering inflates the diff). Label-returning frame cases are never named `/default`.
- Defaults never change silently; a default change is **Changed** in `CHANGELOG.md`. Version pin lives in `pyproject.toml`, `src/paris/__init__.py` and `tests/test_portfolio.py`.
- House hook blocks blanket `git add`; stage explicit paths. Commits end with the Co-Authored-By line.

## Research protocol (binding for `research/`)
- Pre-register before running: `research/<test>/preregistration.json` frozen first (arms, folds, metrics, decision rule, prior). Default verdict RETIRE.
- Tables go to `RESULTS.md` (regenerated by the script); interpretation goes to `READING.md` (hand-written, never overwritten).
- Causality: exposure for day T from information at close T−1; only `jump_labels` is hindsight and nothing may call it in a backtest.
- Scoring: paired cross-fund medians with 1,000-draw bootstrap CIs; Martin + Sharpe primary; MaxDD reported, never gated, with a 50% participation floor; bull-fold bleed measured relative to buy-and-hold; one feature or one parameter per test.
- Universe / folds / cost of record: `research/frozen_rule_benchmark/preregistration.json`; episode calendar and fast-crash subset: `Strategy Research Memos/crash-speed-switch-vs-sizer/preregistration_AB.json`.
- **Every sizing or governor spec carries a weight-matched constant-scale control arm** and is judged against it (H, 2026-09-03: a governor "passed" that was the incumbent × 0.5). Any lookahead bound is fiction, labelled, reported as a ceiling only.
- Pre-registrations that turn out semantically wrong are amended before the run, outcome-blind, with the reason recorded (B, 2026-09-03).
